# Contributing

Use a focused change, explain the concrete failure and resulting behavior, and include a synthetic reproduction. Run the unit tests, compilation and build commands in the README. Format/geometry changes need tests with nonidentity rotations, sparse identifiers, real reader/writer paths, and malformed input where relevant.

Preserve read-only inputs, explicit conventions, non-overwriting output, truthful diagnostics, licensing and upstream attribution. Keep real bags, private captures, prompts, credentials and third-party attachments out of commits. Describe what was actually tested and keep skipped dependencies explicit.
